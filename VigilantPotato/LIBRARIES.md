# Arduino IDE library dependencies

Install these libraries using **Sketch > Include Library > Manage Libraries**:

- DHTesp
- PubSubClient
- Adafruit GFX Library
- Adafruit SH110X

Also install ESP32 board support from Boards Manager (search for **esp32** by Espressif Systems).

Select an ESP32 Dev Module board and use Serial Monitor at 115200 baud.
